## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **React** | Librería principal de UI |
| **React Router DOM** | Navegación entre secciones |
| **React DOM** | Renderizado en el navegador |
| **Vite** | Bundler y servidor de desarrollo |
| **TypeScript** | Lógica de la aplicación |
| **HTML5 & CSS3** | Estructura y estilos |
| **Tailwind CSS** | Estilos y diseño responsive |
| **Lucide React** | Iconografía |
| **EmailJS** | Envío de correos desde el formulario de contacto |

## ⚙️ Instalación y uso local

Sigue estos pasos para correr el proyecto en tu máquina:

```bash
# 1. Clona el repositorio
git clone https://github.com/guiss26/portafolio-guissella.git

# 2. Entra en la carpeta del proyecto
cd portafolio-guissella

# 3. Instala las dependencias
npm install

# 4. Inicia el servidor de desarrollo
npm run dev
```

Luego abre [http://localhost:5173](http://localhost:5173) en tu navegador.
