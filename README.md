
# 🌟 Portfolio Personal — Guissella Pérez

Bienvenido/a a mi portfolio personal, una aplicación web (SPA) desarrollada con React, TypeScript y Tailwind CSS, donde muestro mis proyectos, habilidades y experiencia como desarrolladora frontend/fullstack.

🔗 **Demo en vivo:** [https://my-portfolio-4i2h.vercel.app/]

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **React** | Librería principal de UI |
| **React Hook Form** | Formulario |
| **React DOM** | Renderizado en el navegador |
| **Vite** | Bundler y servidor de desarrollo |
| **TypeScript** | Lógica de la aplicación |
| **Tailwind CSS v4** | Estilos y diseño responsive |
| **React icons** | Iconografía |
| **EmailJS** | Envío de correos desde el formulario de contacto |

---

## ✨ Características

- **Página única (SPA)** con navegación mediante anclas entre secciones.
- **Descarga de CV** directamente desde el botón habilitado en la web.
- **Diseño responsive**, adaptado a móvil, tablet y escritorio.

---

## 📂 Secciones del portafolio

- **Sobre mí** — Una breve presentación de quién soy y qué me apasiona.
- **Proyectos** — Mis proyectos más destacados con descripción y enlaces.
- **Habilidades** — Tecnologías y herramientas que manejo.
- **Contacto** — Formulario para ponerse en contacto conmigo directamente.

## ⚙️ Instalación y uso local

Sigue estos pasos para correr el proyecto en tu máquina:

```bash
# 1. Clona el repositorio
git clone https://github.com/guiss26/my-portfolio.git

# 2. Entra en la carpeta del proyecto
cd my-portafolio

# 3. Instala las dependencias
npm install

# 4. Inicia el servidor de desarrollo
npm run dev
```

Luego abre [http://localhost:5173](http://localhost:5173) en tu navegador.
